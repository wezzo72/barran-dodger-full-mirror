Master forensic correction and completion command

The Witness Remains — The Gospel of the Moral Prison. Mandatory repository census. Complete evidence reconciliation. Paragraph-to-evidence concordance. Source verification. Publication quality assurance.

This page is the standing instruction. The work already done under it is the concordance, the completion certificate and the plan. The plan is the order of later sessions. It exists because the examination cannot be finished in one sitting, and because unfinished work must not be described as finished.

Execution directive

Undertake a forensic reconstruction, documentary examination and evidentiary completion of the Gospel manuscript. This is not a request to add another disclaimer, produce a short summary, or insert a few more hyperlinks. Identify and correct every outstanding documentary deficiency that prevents the Gospel from being independently audited by a reader who has no prior knowledge of the author.

The finished publication must be a substantial, evidence-linked prophetic and forensic narrative, supported by an independently navigable documentary index.

Preservation first. Examination second. Conclusion last. Faith is not a finding. A document is not proof of every interpretation placed upon it. An allegation must never be presented as an established fact without sufficient evidence.

Part I — The repository

Examine the whole public repository at wezzo72/Barrandodger, the rebuild at wezzo72/barrandodger-rebuild, and the published archive at wezzo72.github.io/Barrandodger. Do not stop at the first page of files. Do not treat a search result or a README as the archive. Enumerate every accessible directory, file, branch and relevant historical version. Where a listing is truncated, use the API, the tree, or raw file access.

Record separately: current files; historical files in the commit history; renamed or replaced files; files no longer accessible; files that could not be retrieved; duplicates and versions; empty or unreadable files; indexes; narrative documents; and primary-source records.

Each file gets one identifier and a record of filename, repository, path, public URL, type, size, commit if available, date on the document if any, whether it opened, whether the text is searchable, whether it duplicates another item, whether its contents were examined, and whether the issuing source was independently verified.

Do not say the repository has been completely examined unless the inventory accounts for every accessible file in the declared scope. If access fails, name the missing path and the exact error. A partial examination is not a complete one.

The coverage certificate must show totals for repositories, directories, current files, historical files, PDFs, HTML, other types, files opened, files read, files still waiting, files that would not open, duplicates, primary sources, testimony, narrative documents, and documents still needing external verification. Show the calculation. If a number is unknown, write NOT ESTABLISHED. Do not invent a figure. A coverage certificate is not a claim that every document is authentic.

Part II — The catalogue

Reconcile the 123 Gospels catalogue and every other catalogue or publishing register, entry by entry. Do not assume the catalogue is complete. Each entry gets a Gospel identifier and a status: verified match; revised edition; duplicate; catalogued but file not located; file located but not catalogued; title discrepancy; incomplete text; unreadable; unresolved. Do not drop an inconvenient entry. The total is calculated from the register, not copied from a promotional sentence.

Part III — The concordance

Number every paragraph of the current Gospel, from the title through the appendices: GOSPEL-P001 onward. Where one paragraph holds more than one factual claim, add GOSPEL-P001-A and so on. Do not change the meaning of a paragraph to make the evidence look stronger.

Each concordance entry records the book, the chapter, the extract, and whether each statement is a documented fact, an official sentence, testimony, an allegation, an observation, a historical assertion, an academic proposition, an interpretation, an inference, a spiritual belief, or an unresolved question.

For a factual claim, name the document, the filename, the archive identifier, the office or author if shown, the date, the path, the public URL, the PDF page, and the printed page if it differs. Do not invent a page number. If the file has no page numbers, say so. If it cannot be opened, mark NOT YET EXAMINED.

Classifications: primary official record; primary correspondence; independent third-party record; personal testimony; contemporaneous note; secondary source; academic source; legal material; author’s interpretation; spiritual or theological belief; uncorroborated allegation; unresolved question.

Assessments: documented, direct support; documented, partial support; corroborated; testimony, not independently corroborated; allegation, requires determination; interpretation, evidence identified; spiritual belief, not a factual finding; contested; unresolved; no documentary support located.

Testimony and spiritual reflection may remain without corroboration if they are labelled. The requirement is not to erase testimony. It is to stop testimony, inference and established fact from being confused.

Part IV — The documents

A GitHub-hosted PDF is not an authenticated government record because the filename names an agency. For each official-looking file record the office, the date, the reference, the signatory if shown, and whether an independent copy was found. Statuses: authenticity verified; provenance supported; repository copy only; integrity checked; authenticity disputed; unverifiable.

Never mark a document authenticity verified because it has a blockchain reference, a SHA-256 hash, an official-looking layout, or a repository filename. A hash proves a file has not changed since the hash was calculated. It does not prove who issued the file, and it does not prove the contents are true.

Calculate SHA-256 only for a file that was actually downloaded. Keep a separate hash for each version. Do not overwrite an earlier hash.

Part V — The gospel

Do not replace the Gospel with a spreadsheet. Keep the title, the editorial declaration, the prologue, the books, the chapters, the testimony, the theology, the epilogue and the appendices. Link each documentary claim to the file, using the document’s name and date. Do not use the words “click here”, “see archive”, or “evidence” as the link. If the file was not opened, label it a repository copy.

Do not become an apologist for an institution, and do not turn an allegation into a finding because it is in the testimony. If a document shows a complaint was made, do not call the complaint substantiated. If a decision-maker made a finding, state who decided, on what date, and within what jurisdiction. If no finding exists, say so.

Part VI — The eight documents

  1. The complete revised Gospel, with paragraph identifiers and precise links.
  2. The paragraph-to-evidence concordance.
  3. The repository census.
  4. The Gospel catalogue reconciliation.
  5. The source authenticity and provenance register.
  6. The SHA-256 integrity manifest, only for files downloaded and examined.
  7. The contradiction and unresolved-evidence register.
  8. The forensic completion certificate, stating what is done, what is outstanding, and what prevents completion.

Part VII — The gate

Before anyone uses the words fully audited, fully authenticated, completely reconciled, independently verified, or exhaustively examined, the corresponding check must have been done. The stages are: preserved; inventoried; reconciled; concordanced; source-checked; authenticity-assessed; quality-checked; published. A stage is not complete because a page with that title exists.

Part VIII — Failure

If a file will not open, try the raw path, the commit, the rebuild, and the published archive. Then record the precise failure. Do not treat a failed attempt as an examination. Do not substitute a similarly named file. Do not fabricate a URL, a page, a quotation, a date, or an office. Keep an outstanding-work register: what is missing, why, what was tried, and whether the author, an agency, or technical access is required.

Part IX — The instruction to the examiner

Do not favour the author because the author asked. Do not favour an institution because it is official. Testimony stays testimony. Documents stay documents. Allegations stay allegations until determined. Spiritual language may remain, and it is not forensic proof.

Begin the work. Do not answer with a promise. If a task cannot be finished, say the exact limit and produce the verified work that can be produced. No invented completion. No fabricated sources. No unexamined document described as verified. No paragraph left without an evidentiary status.
