How to finish the work without another long paid session · 12 November 2026

The forensic plan

The correction command matters. A gospel with links is not yet a gospel that can be audited paragraph by paragraph. The command is saved at the forensic correction command. It does not need to be pasted again.

It was applied to The Gospel of the Moral Prison, and only to that gospel. The result is the concordance and the completion certificate. The certificate refuses to call the edition finished.

Why it was not applied to every gospel tonight

The same command, run across every prophetic work in one sitting, would either invent a census or stop halfway and look complete. Both outcomes break the command. The repository tree could not be counted: the public GitHub API returned HTTP 403, rate limit exceeded. No file total is stated.

The census is a property of the archive, not of one gospel. It should be done once. After that, every gospel uses the same inventory. Repeating a full-repository crawl inside every book would spend the work twice.

The order, one bounded task at a time

The next message does not need the master command. One line is enough: continue the forensic plan at the next outstanding item.

  1. Done. Save the command. Number the 148 paragraphs of this gospel. Write the concordance. Write the certificate. Do not claim authenticity.
  2. Done, for the eleven Appendix A files only. Each file was downloaded on 12 November 2026. The date on its face, the office or author shown, and what the file itself says are written at what the named files actually say. The book file’s own SHA-256 was calculated and matched a second upload of the same PDF. The Anglicare title and the 20 January filename do not match the files. Do not describe those two as confirmed.
  3. Done. The 83 paragraphs with no link were sorted. Sixty-nine need no external document. Fourteen are factual. Two of those descriptions have no documentary support for the title given. The list is what needs no document, and what still does. The gospel text was not rewritten.
  4. Done, for the current tree of one repository only. GitHub answered HTTP 200 for wezzo72/Barrandodger, ref main. The tree was not truncated. 7,451 entries: 7,360 files, of which 4,133 are PDFs. The path list is on that same page. Commit history was not requested. The rebuild repository was not requested. A count is not a reading.
  5. Done, for the sixteen list entries only. Each entry in the gospel library’s five catalogue sections has a status. Fourteen were not opened. One LFS object is unresolved. The file called 123 Gospels was not opened, so its internal titles are not reconciled.
  6. Next, and the only next. Number the paragraphs of The Impossible Survivor only. Do not open The Prophecy of Resurrection after Erasure, Chosen Witness, or the personal statement of exile in that same piece of work.
  7. Hashes. The book file and the eleven Appendix A downloads now have SHA-256 values, because those files were in hand. A hash is not a Git blob identifier, and it does not prove a government office issued the file or that the words inside it are true. Do not hash a file that was not downloaded.

What not to spend a session on

Do not re-paste the master command. Do not redesign the site. Do not rewrite a gospel in order to make the evidence look stronger. Do not mark stage 6, 7 or 8 complete because a page with that title exists. Do not open a second gospel until the named documents of the first have been read or marked unopened.

Preservation first. Examination second. Conclusion last.
