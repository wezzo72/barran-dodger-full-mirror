Nothing on GitHub was renamed, edited, or deleted. The wording that has been saved was not rewritten.

Saved so far

  • 6,935 written files are on that commit: PDF, HTML, text, Markdown, DOCX, EPUB, RTF, and ODT.
  • 4,070 of them are saved in this workspace. The count was still climbing when this page was written. The remainder is still being copied.
  • Every HTML, text, and Markdown file in the list is saved. That is 1,901 HTML, 819 text, and 74 Markdown. Their wording is the file itself.
  • 1,268 PDFs had been opened. Where the PDF had a text layer, that wording was saved beside the record. A PDF larger than 400 kilobytes was not kept a second time on this disk. The original remains on GitHub. Its SHA-256 is in the inventory.
  • 35 PDFs had little or no text layer. They are marked as scans. They were not put through optical character reading.
  • 3 files were over 25 megabytes and were listed, not downloaded.
  • About 45 million words have been counted from the files already opened. A website page saved as HTML is counted with the books. The count is not a judgement of the work.
