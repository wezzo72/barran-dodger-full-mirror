What was not done

  • The text inside the 6,950 files was not extracted. Word counts, page counts, footnotes, and scripture indexes were not made. The column in the CSV says “no”. The obstacle is the size of the archive, 4,133 PDFs, not a refusal by the connected GitHub account.
  • No SHA-256 of the file bytes was calculated in this pass. A Git blob identifier is not that hash.
  • Scanned pages were not put through optical character recognition.
  • Private repositories were not found in the earlier public list. None were opened.
  • Credentials, tokens, and private keys were not searched for and are not in this catalogue.
  • The full history of every commit was not preserved as a second copy.

How to preserve what is already public

  • The originals stay on GitHub. This catalogue does not replace them.
  • Keep a second copy offline: download the repository as a zip from GitHub when the rate limit allows, and store that zip on a disk that is not this website.
  • A content hash has to be made from the downloaded bytes. Until that is done, do not claim a SHA-256 for these files.
  • Do not merge, rename, or delete an original until you have said so in a later instruction.

The wider file index, including non-written files, remains at barrandodger-main.csv and repository-register.csv.
